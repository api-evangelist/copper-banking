# Copper Banking

> Copper (Copper Banking) is a Seattle-based consumer fintech founded in 2019 by Eddie Behringer and Stefan Berglund. It launched as a teen banking app and debit card on the Synapse banking-as-a-service platform, discontinued its bank deposit accounts and debit cards in May 2024 after Synapse collapsed, and repositioned as a financial-empowerment and earning app where members earn cash and gift-card rewards through cash back, paid surveys, receipt scanning, games and referrals, alongside financial-literacy content and in-school workshops.

Copper publishes no public developer portal, no API documentation, and no API specification. The only machine-readable surface reachable without credentials is an OAuth 2.0 authorization server for a Model Context Protocol endpoint at mcp.getcopper.com, which Copper does not document.

## APIs

- [Copper MCP Server](https://mcp.getcopper.com/): Undocumented Model Context Protocol server. Publishes RFC 8414 OAuth 2.0 Authorization Server Metadata declaring the `mcp` and `offline_access` scopes, authorization-code grant with PKCE (S256), refresh tokens, and RFC 7591 dynamic client registration. The transport endpoint is not discoverable anonymously, so the tool list and input schemas cannot be introspected.

## Specs

- [OAuth 2.0 Authorization Server Metadata](https://mcp.getcopper.com/.well-known/oauth-authorization-server): RFC 8414 discovery document for the MCP server.

## Notes

- There is no public Copper developer API. `gateway.api.getcopper.com` is the private backend for Copper's own mobile and web apps and publishes no specification or documentation.
- `app.getcopper.com` still serves the pre-May-2024 Copper Banking single-page app, whose bundle still references the defunct Synapse platform.
- Do not confuse this company with Copper CRM (copper.com / developer.copper.com) or Copper.co (digital asset custody, docs.copper.co). They are unrelated companies that share the name.
